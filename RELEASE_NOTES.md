Release Notes — v1.1.0

Оновлення зосереджене на покращенні архітектури коду (зниження зв'язності модулів) та актуалізації тарифів на доставку.

Added
- Спеціальний тариф для Києва:** додано фіксовану базову ставку доставки `80.0` для міста `"Kyiv"` (при збереженні `50.0` для `"Ivano-Frankivsk"` та `110.0` для інших міст).
- Явний параметр податкової ставки:** у функцію `process_standard_invoice` додано аргумент `tax_rate` зі значенням за замовчуванням `0.20`.
- Окрема функція для звільнених від податку рахунків:** додано функцію `process_tax_exempt_invoice(...)` для прозорої обробки замовлень без ПДВ.

Changed
- Підвищено тариф за вагу:** коефіцієнт вартості доставки за кожен кілограм ваги збільшено з `12.0` до `15.0`.
- Перехід до Data Coupling:** усунено дефекти зв'язності (*Common Coupling*, *Stamp Coupling* та *Control Coupling*). Функції розрахунку тепер приймають виключно необхідні примітивні параметри (`city`, `weight_kg`) замість усього об'єкта `CustomerProfile`.

Breaking Changes
- Видалено глобальний стан:** глобальну змінну `GLOBAL_TAX_RATE` повністю вилучено з кодової бази.
- Видалено прапорець керування:** параметр `mode_flag` та єдину функцію `process_invoice(...)` видалено. Замість неї потрібно викликати `process_standard_invoice(...)` або `process_tax_exempt_invoice(...)`.
- Змінено сигнатури функцій:** функція `calculate_delivery_cost(customer, weight_kg)` тепер має сигнатуру `calculate_delivery_cost(city, weight_kg)` і більше не приймає екземпляр класу `CustomerProfile`.
